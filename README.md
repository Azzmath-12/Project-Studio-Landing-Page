# Creative Studio & Digital Agency Landing Page

A modern, responsive landing page designed for creative studios, digital agencies, and design consultants. Built with semantic HTML5, custom CSS3, and Bootstrap Icons to showcase agency offerings, portfolio highlights, pricing tiers, team members, and inquiry channels.

---

## 🚀 Live Demo

[View Live Project](https://azzmath-12.github.io/Project-Studio-Landing-Page/)

---

## 📌 Features

- **Hero & Search Header**: Full-bleed hero banner featuring headline typography, background imagery, and a search bar.
- **Interactive Service Cards**: Grid layout featuring hover states that transition icons to accent-styled action points.
- **Client Testimonial**: High-contrast, dark-themed quote highlight with quote iconography.
- **Studio Showcase**: Responsive multi-column gallery highlighting photography and studio capabilities.
- **Call to Action (CTA)**: Mid-page conversion banner with overlay imagery and action buttons.
- **Team Profiles**: Team cards displaying circular portrait imagery, roles, descriptions, and linked social media icons.
- **Pricing Tiers**: Tiered subscription cards with custom pricing badges, feature lists, and hover effects.
- **Client Reviews & Logos**: Dedicated review cards paired with an enterprise client logo strip.
- **Interactive Accordion & FAQ**: Pure CSS radio-driven expandable inquiry panels paired with contextual description blocks.
- **Contact & Location Details**: Split-view contact form with input validation, address details, and footer navigation.
- **Fully Responsive**: Media queries providing fluid layouts across desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure and markup.
- **CSS3**: Custom properties (variables), Flexbox, CSS Grid, hover transitions, and responsive media queries.
- **Bootstrap Icons**: Vector iconography for service markers, ratings, and social profiles.
