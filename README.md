# Creative Studio & Digital Agency Landing Page

A modern, responsive landing page designed for creative studios, digital agencies, and design consultants[cite: 5]. Built with semantic HTML5, custom CSS3, and Bootstrap Icons to showcase agency offerings, portfolio highlights, pricing tiers, team members, and inquiry channels[cite: 5].

---

## 🚀 Live Demo

[View Live Project](https://azzmath-12.github.io/Project-Studio-Landing-Page/)

---

## 📌 Features

- **Hero & Search Header**: Full-bleed hero banner featuring headline typography, background imagery, and a search bar[cite: 5].
- **Interactive Service Cards**: Grid layout featuring hover states that transition icons to accent-styled action points[cite: 5].
- **Client Testimonial**: High-contrast, dark-themed quote highlight with quote iconography[cite: 5].
- **Studio Showcase**: Responsive multi-column gallery highlighting photography and studio capabilities[cite: 5].
- **Call to Action (CTA)**: Mid-page conversion banner with overlay imagery and action buttons[cite: 5].
- **Team Profiles**: Team cards displaying circular portrait imagery, roles, descriptions, and linked social media icons[cite: 5].
- **Pricing Tiers**: Tiered subscription cards with custom pricing badges, feature lists, and hover effects[cite: 5].
- **Client Reviews & Logos**: Dedicated review cards paired with an enterprise client logo strip[cite: 5].
- **Interactive Accordion & FAQ**: Pure CSS radio-driven expandable inquiry panels paired with contextual description blocks[cite: 5].
- **Contact & Location Details**: Split-view contact form with input validation, address details, and footer navigation[cite: 5].
- **Fully Responsive**: Media queries providing fluid layouts across desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure and markup[cite: 5].
- **CSS3**: Custom properties (variables), Flexbox, CSS Grid, hover transitions, and responsive media queries[cite: 5].
- **Bootstrap Icons**: Vector iconography for service markers, ratings, and social profiles[cite: 5].
